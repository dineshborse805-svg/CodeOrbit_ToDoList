# CodeOrbit Tech - To-Do List CLI App

## Task 2: To-Do List CLI App

A simple command-line To-Do List application built using Python as part of the CodeOrbit Tech Python Programming Internship.

## Features

- Add new tasks
- View all tasks
- Remove tasks
- Numbered task list
- Input validation
- Functions used to organize each feature
- Simple command-line interface

## Requirements

- Python 3.x
